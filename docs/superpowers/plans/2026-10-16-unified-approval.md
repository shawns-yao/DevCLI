# 统一审批与项目信任

范围：主机命令统一经过工具审批；规则先于模式和分类器；auto 直接接受项目编辑；分类器拦截达到连续 3 次或累计 20 次后退出 auto 并询问。硬拒绝、敏感内容和强制逐次确认保持有效。

项目信任保存在用户目录，按规范化项目路径隔离。首次交互启动询问，拒绝后主机命令逐次确认。无交互入口只读取已有决定。信任不等于授权全部命令；仅解除主机命令对规则和 auto 的限制。

命令审批展示可保存的窄前缀，用户明确选择后持久化该项目的 permissions.allow。命令包含 Shell 复合语义或解释器执行参数时不提供前缀保存。移除 /grant commands，/grant all 只保留写入；已确认计划的内部命令授权继续保留。

步骤：

1. 统一命令执行入口和审批顺序，清除旧主机审批路径；增加 auto 拦截计数。
2. 增加项目级信任存储、启动确认和命令前缀审批；同步 CLI 与无交互接线。
3. 更新定向测试、注释、规范及 ADR 0021，运行定向、quick 和终端兼容回归。
4. 按功能提交并推送；保留 pelican-bicycle.html。
