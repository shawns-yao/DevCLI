# Windows 原生隔离实施计划

目标：复用现有工作区与 PatchSet，新增显式选择的 AppContainer 离线执行后端。Docker 与主机模式保留原行为，不自动降级、不放宽审批。

技术：Java 17 执行适配器、.NET 8 Windows 原生 API 启动器；不安装系统账户或 WFP 规则。

- [x] 核实 SRT 的共享 SID 与 DNS 边界，选择 AppContainer。
- [x] 定向失败用例：原生模式识别、缺少启动器不执行、MCP 配置失败关闭。
- [x] 实现独立身份、空网络能力、显式文件授权、环境重建、句柄白名单与 Job 生命周期。
- [x] 命令执行接入，保持工作区与归并路径不变。
- [x] 本地 stdio MCP 接入只读离线模式，远程 MCP 不宣称受本机沙箱保护。
- [x] 定向验证文件访问、网络、子进程、取消、并发工作区、MCP 初始化与关闭。
- [x] 构建与相关回归；检查差异、文档及未验证边界。

影响范围：`tool/command`、`sandbox`、`mcp`、原生启动器、配置说明。现有主机单次审批保持不变。

执行限制：不启动子代理，不创建新工作树，不提交或推送；不安装机器级组件。原生构建输出放入已有忽略的 `target/`。
