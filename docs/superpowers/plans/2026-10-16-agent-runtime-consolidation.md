# Agent 运行时收敛实施计划

**目标：** 统一委派和工作计划，稳定工具前缀，按需读取记忆，按职责拆分超过 1500 行的核心类。

**架构：** 按用户确认的 B 方案，主 Agent 默认写入；worker 同步运行并独占写入阶段，后台仅 explorer/reviewer。复用现有隔离工作区、硬检查、PatchSet、权限管线及恢复记录，不修改资源租约策略。

**技术栈：** Java 17、Maven、JUnit 5、现有 ToolRegistry / AgentExecutionEngine / RunStore。

每阶段先做相关定向验证，覆盖准入并发、目标工具权限、工具前缀稳定、工作计划压缩/恢复、记忆作用域和工具结果引用。用户已于 2026-10-16 授权 quick 回归和临时 SQLite 测试，通过后按功能提交，并补充授权推送及收录已有功能改动。测试索引指定 target 下目录；不启动产品服务、不连接业务数据库。真实模型效果与缓存收益未验收。普通目录夹具位于用户 Git 仓库内时明确跳过该用例，嵌套仓库和损坏元数据隔离分别执行。
