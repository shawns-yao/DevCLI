# 删除工具名称屏蔽与轻量执行身份

日期：2026-10-16

## 背景

统一委派后，补丁工具仍注册并在四处按名称屏蔽；委派准入和执行各维护一份禁用清单。MCP 要求模型回传 schema 指纹，重复了目标当前 schema 的参数校验。Worker 已不执行独立循环，却仍创建完整 SubAgent 保存身份。

## 决定

- 不注册 `apply_patch`，删除 ApplyPatchTool、专用审批检查及失效测试。保留 ApplyPatchParser、ApplyPatchCompiler 和 PatchSet 内部 API。
- 工具契约显式声明主 Agent 归属；准入、发现和执行共用该声明与角色能力，不维护第二份委派禁用工具清单。
- `call_mcp_tool` 只接收工具名和参数。搜索仍返回完整 schema，执行按当前绑定经过参数、权限、Skill、审批及审计管线；生命周期快照的内部指纹保持原用途。
- Worker 身份只保存字符串列表，沿用 checkpoint 协议 10 的身份、游标和步骤绑定。批次只负责资源分波、并发上限和输出归并，删除 Worker 对象、实例锁和无效 fork 装配。
- SubAgent 保留计划生成和独立审查职责；删除无调用方的 Worker 上下文接口及强制执行分支。主 Agent 所用的命名工具信封解析归入 RequiredToolProtocol。

## 验证边界

定向组件回归检查未注册工具、MCP 当前 schema、归属权限、身份恢复和只读并发/写入串行。quick 回归使用模型替身与临时文件/SQLite，不代表真实模型、生产缓存收益或完整能力验收。
