# 编码工具与无交互入口

日期：2026-10-16

## 决定

- 取消 search_code 注册并删除 RagToolProvider；显式索引命令、RAG 组件和历史证据处理保留，模型使用 glob/grep_code/read_file 定位代码。
- 白名单构建/测试与只读 Git 命中显式 allow 时可免主机审批；拒绝与 ask 规则优先，其他命令仍逐次确认。白名单不隔离项目构建代码，不新增授权配置或后台进程功能。
- execute_command 增加 timeout（秒，1–86400）。执行器显式声明本次期限，贯通工具取消和进程终止，显式超时可覆盖默认批次上限。审批和排队计入期限，不改变父任务取消。
- edit_file 增加 replace_all；精确匹配失败时复用 SeekSequence 的完整行空白匹配，采用最严格有命中的层级并检查全部歧义。glob 复用 Git 文件枚举和忽略规则。
- Main 增加 -p，通过现有 AgentSessionRuntime 运行一次任务。仅装配内置工具，使用现有模型、权限和规则；stdout 为单个 UTF-8 JSON，诊断写 stderr，需要临时审批时拒绝，退出码区分运行结果。运行完成与任务验收分开。
- model.usage trace 与 -p usage 记录缓存命中率，不引入额外模型请求，不用该指标替代真实 A/B。

## 验证边界

组件与集成测试覆盖权限优先级、真实主机审批/超时、替换和文件发现、替身模型会话及真实 Main 参数错误子进程。quick 与交互冒烟仅证明覆盖路径，不代表真实模型能力或缓存收益。
