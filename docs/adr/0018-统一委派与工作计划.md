# 统一委派、工作计划和稳定工具前缀

日期：2026-10-16

后续收敛：工具注册、MCP 调用参数和 Worker 身份的实现修订见 [ADR 0019](0019-删除工具屏蔽与轻量执行身份.md)，以下初始决定中的模型指纹和补丁工具隐藏方式由该记录替代。

## 背景

ReAct 委派与 `/plan` 曾分别维护子循环、工作区提交和失败处理。并行写入能隔离文件冲突，但不能统一实现决策。MCP 激活和每轮工具路由会改变请求中的工具定义。长期记忆选择器额外调用模型，ReAct 缺少主动维护当前工作与下一步的入口。

动态记忆、Skill 索引和工作记忆原已追加到当轮消息；编辑后的 LSP hook 原已存在。恢复快照主要是投影，不应视为多个独立权威状态。

## 决定

- 子任务统一使用 `DelegationSession`（`delegate_task` 的执行原语）。`/plan` 保留确认、DAG、最终验收和 checkpoint，删除独立 Worker 执行与重试链路。checkpoint 协议仍为 10，旧记录经既有迁移器恢复；deferred PatchSet 在新作用域登记局部写入，提交沿用写前日志与版本闸门。
- 主 Agent 默认写入；写角色同步运行，主 Agent 等待。同一运行中的写角色不可重叠，后台只允许只读能力；资源租约、隔离工作区、硬检查和 PatchSet 继续执行。
- 后台线程池工厂下沉到 `concurrent.BackgroundWorkers`，避免 Agent 依赖托管它的 runtime 包；队列、线程和状态生命周期保持原语义。
- 角色作为数据加载：内置 `explorer/worker/reviewer`，用户 `~/.devcli/agents/*.md`，项目 `.devcli/agents/*.md`，后者覆盖前者。frontmatter 定义名称、说明、能力、工具和可选模型，正文为提示词。目录在项目绑定时冻结，fork 继承相同目录。角色名不授予权限；能力和工具清单继续被父级、Skill 与副作用策略收窄。planner 可用自定义文件添加；完整上下文顾问模式留待后续。
- 模型工具定义在执行循环内固定；不再按回合路由删选。`search_tools` 返回目标 schema 和指纹，固定 `call_mcp_tool` 校验已发现目标、指纹、参数后进入目标原执行管线。目标变更时拒绝旧指纹；权限、审批、审计和结果治理不被旁路。最后一轮禁用工具用原生 `tool_choice=none`，保留定义。Project Context 移入当轮消息。
- `update_plan` 的唯一值保存在 `SessionMemory.taskState.agent_work_plan`；当前工作和下一步由步骤状态导出。ReAct 和 `/plan` 共用，压缩和恢复原样携带，普通恢复预算不截断该值。`TaskLedger`、工具证据和 `ExecutionArtifact` 保留执行投影与真实终态，计划标记不能替代证据。
- 每轮只注入长期记忆索引，删除选择器模型调用。`read_memory` 仅按已绑定作用域和主题名读取，不扩大 `read_file` 围栏。
- 旧工具结果按历史顺序和最近 Token 预算回收。先保存原文与哈希，确认引用更短才替换；失败保留原文，工具消息配对不变。
- 模型编辑工具保留 `write_file/edit_file`；删除仍使用 `delete_files`。`apply_patch` 仅保留内部 API，模型定义隐藏，模型批次调用拒绝。
- Main 拆启动、输入、轮次和计划交互；ToolRegistry 拆目录、类型、权限上下文与执行装配；压缩器拆回收、窗口、摘要和恢复；VectorStore 拆结构维护、事务与检索。共享状态留在明确的拥有者中，不复制第二份。

## 关键取舍

全部子任务只读最简单，但会失去把机械修改交给隔离 worker 的能力。此次保留同步写角色，接受写入阶段串行的代价。只读探索仍可并发；这不是所有编码任务均应单写入的普遍结论。

仅冻结工具列表会让新发现工具无法调用，因此增加固定执行入口。工具前缀可复用不等于已有可量化缓存收益；实际命中率、延迟和成本仍需真实请求对照。

工作计划和执行证据保持各自语义。压缩保存同一计划的投影，不让摘要再生成一份可能冲突的待办清单。

## 后果

原后台 worker 请求现在直接拒绝；依赖内置 planner 或旧提示词覆盖路径的配置需要改为角色文件。旧 Worker 专用协议测试随旧路径删除，权限、恢复、预算和提交边界继续验证。

组件验证使用模型替身和临时文件/SQLite；quick 回归仅证明其覆盖范围，不代表真实模型、生产缓存收益或完整能力验收。未启动产品服务、未连接业务数据库。
