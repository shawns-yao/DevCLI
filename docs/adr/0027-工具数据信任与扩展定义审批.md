# ADR 0027：工具数据信任与扩展定义审批

状态：已接受，2026-10-17。补充 ADR 0007 的主动经验保存与 ADR 0008 的工具数据信任边界。

## 已核对的问题

长期记忆索引已经显示 updated_at，SessionMemory 与 MemoryManager 已在 1000 行以内，不另建记忆层，也不删除证据 epoch。真正的问题是 save_memory 把所有模型调用标记成用户显式请求，允许覆盖已有主题。MCP 发现指纹此前只含名称与 schema，服务级批准清理没有删除该服务的工具级批准。主提示词没有明确区分工具正文和执行授权，Skill 同名覆盖未在列表展示。

## 决定

- save_memory 增加 intent，默认 agent_experience，只接受 project/feedback，沿用不覆盖已有主题的存储路径。user_request 仅用于用户明确保存或更新，允许既有四种类型及修订。两者仍完整展示内容并单次审批；意图字段是模型声明，不是可验证的用户授权，审批承担最后确认。删除丢失元数据的旧纯文本保存接口。
- 记忆仍只注入索引，正文按需读取；提示词要求使用前核实相关文件、符号、配置和命令。更新时间不能证明内容有效。
- ToolResultContext 从原始消息生成请求视图，JSON 封装来源、调用 ID、UNTRUSTED 和独立正文。事件日志与工具内部解析继续使用原始数据，model.context 记录实际请求视图。结果预算包含编码开销；摘要请求也使用该边界。正文中的同名字段不能伪造外层标签。
- 第三方 MCP 描述展示上限为 2000 个码点，标明来源；完整 schema 保留以供参数校验。发现指纹覆盖描述、schema、annotations，保留原 schemaFingerprint 字段名。对象键序不构成定义变化。
- 已有 MCP 定义变化时撤销该服务的服务级和工具级批量批准。变化的工具必须单次人工确认，不被规则、权限模式或缓存批准覆盖。执行前再次校验审批绑定的定义；审批中更新或旧 fork 继续调用时拒绝。新增/移除工具同样清除服务批量批准，不引入模型抄回指纹的参数。
- Skill 覆盖复用现有加载诊断，列明获胜与被覆盖的来源和文件。索引显示来源；加载时用英文词和汉字二元组的 Jaccard 提示相似描述，阈值 0.75、双方至少 4 个词项。诊断不参与选取、停用或权限合并；不增加模型选择器。描述须明确使用与排除场景，词面相似不代表语义冲突。

## 边界与验证

UNTRUSTED 标签和提示词不是语义注入检测器，也不能证明工具服务实际实现与描述相同；权限、单次审批、外发审查和沙箱继续生效。MCP 校验约束的是客户端已观察到的定义，不能保证调用后的服务端行为不变。Skill 相似度只提供人工检查线索。

本轮按用户要求先实现，不执行测试、真实 MCP 或模型调用。新增和调整的回归用例只进行测试源码编译，不能表述为测试已通过；实际执行结果在后续获准测试时报告。
